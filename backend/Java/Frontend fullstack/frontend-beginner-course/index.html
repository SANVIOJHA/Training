Beginner Friendly Course

Frontend Foundations

This course is organized into three folders: HTML, CSS, and JavaScript. Each section teaches the concepts from scratch with simple explanations, examples, and practice tasks.

How to study this course

  1. Start with HTML first.
  2. Then learn CSS to style the HTML.
  3. Then learn JavaScript to add behavior.
  4. Practice every example by typing it yourself.
  5. Change the code and observe what changes in the browser.

Folder 1

HTML

Learn structure, tags, forms, semantic HTML, tables, accessibility, and page building.

Folder 2

CSS

Learn selectors, colors, fonts, spacing, box model, positioning, Flexbox, Grid, and responsive design.

Folder 3

JavaScript

Learn variables, conditions, loops, functions, arrays, objects, DOM, events, async code, and APIs.

Recommended order

  • Week 1 and 2: HTML
  • Week 3 and 4: CSS
  • Week 5 to 8: JavaScript
  • After that: combine all three in mini projects
