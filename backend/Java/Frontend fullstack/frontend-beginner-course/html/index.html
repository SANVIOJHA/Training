Learn HTML from Scratch

HTML stands for HyperText Markup Language. It is used to create the structure of a webpage. HTML does not focus on beauty or logic. Its main job is to describe what the content is.

Chapter 1: What HTML is and why we use it

HTML gives meaning and structure to a webpage. It tells the browser which text is a heading, which part is a paragraph, which part is an image, and which part is a button or form.

Why HTML is important

  • Every webpage starts with HTML.
  • It creates the skeleton of the page.
  • CSS and JavaScript both depend on HTML.

Think of HTML like this

  • HTML = structure of a house
  • CSS = paint and decoration
  • JavaScript = electrical behavior and interactions

Chapter 2: Basic HTML document structure

Every HTML page follows a basic structure. This is the first code you should memorize and understand. 

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My First Webpage</title>
</head>
<body>
  <h1>Hello</h1>
  <p>Welcome to HTML.</p>
</body>
</html>
  • `DOCTYPE` tells the browser to use HTML5.
  • `html` is the root element.
  • `head` contains page information.
  • `body` contains the visible content.

Chapter 3: Headings, paragraphs, and text tags

These are used for writing readable content on the page. 

<h1>Main Heading</h1>
<h2>Subheading</h2>
<p>This is a paragraph.</p>
<strong>Important text</strong>
<em>Emphasized text</em>
Use `h1` for the main title of the page. Use `h2`, `h3`, and others in proper order. Do not skip heading levels just for size.

Chapter 4: Links, images, and paths

Links help users move to another page or website. Images add visual information. 

<a href="https://www.example.com">Visit Example</a>

<img src="images/profile.jpg" alt="Profile photo">
  • `href` tells the link where to go.
  • `src` tells the browser where the image is.
  • `alt` describes the image and is important for accessibility.

Chapter 5: Lists

Lists are used when content belongs together in a group. 

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

<ol>
  <li>Open editor</li>
  <li>Write code</li>
  <li>Run in browser</li>
</ol>
  • `ul` is unordered list.
  • `ol` is ordered list.
  • `li` is list item.

Chapter 6: Tables

Tables are only for tabular data such as marks, schedules, and price lists. Do not use tables for page layout. 

<table>
  <tr>
    <th>Name</th>
    <th>Marks</th>
  </tr>
  <tr>
    <td>Riya</td>
    <td>92</td>
  </tr>
</table>

Chapter 7: Forms and input fields

Forms are used to collect user input like names, passwords, messages, and choices. 

<form>
  <label for="name">Name</label>
  <input id="name" type="text" placeholder="Enter your name">

  <label for="email">Email</label>
  <input id="email" type="email">

  <label for="message">Message</label>
  <textarea id="message"></textarea>

  <button type="submit">Submit</button>
</form>
  • Use `label` for every input.
  • Use `button` for actions.
  • Use `required` when the field must be filled.

Chapter 8: Semantic HTML

Semantic HTML means using meaningful tags instead of using `div` for everything. 

<header>Website Title</header>
<nav>Menu links</nav>
<main>
  <section>
    <article>Blog post</article>
  </section>
</main>
<footer>Footer content</footer>
Semantic HTML helps accessibility, code readability, and SEO.

Chapter 9: Inline vs block elements

Block elements usually start on a new line. Inline elements stay within the line.

  • Block examples: `div`, `p`, `h1`
  • Inline examples: `span`, `a`, `strong`

Chapter 10: HTML attributes

Attributes provide extra information to an element. 

<input type="text" id="username" class="field" placeholder="Enter username">
  • `id` is unique.
  • `class` is reusable.
  • `placeholder` shows hint text.
  • `type` tells what kind of input it is.

Chapter 11: Accessibility basics

  • Use labels for form fields.
  • Use meaningful button text.
  • Use alt text for images.
  • Use headings in proper order.
