Learn CSS from Scratch

CSS stands for Cascading Style Sheets. It is used to style HTML content. CSS controls colors, fonts, spacing, alignment, layouts, and responsiveness.

Chapter 1: What CSS is and why we use it

HTML gives structure, but the page will look plain without CSS. CSS makes the page attractive and easier to read.

  • HTML says what the content is.
  • CSS says how the content should look.

Chapter 2: Ways to add CSS

Inline CSS:
<p style="color: red;">Hello</p>

Internal CSS:
<style>
  p { color: red; }
</style>

External CSS:
<link rel="stylesheet" href="styles.css">
External CSS is the best choice for most projects because it keeps styling separate from HTML.

Chapter 3: CSS syntax

selector {
  property: value;
}
h1 {
  color: blue;
  font-size: 32px;
}

Chapter 4: Selectors

p {
  color: green;
}

.card {
  background: white;
}

#main-title {
  color: brown;
}
  • Element selector targets all matching tags.
  • Class selector is reusable.
  • ID selector is for one unique element.

Chapter 5: Colors, backgrounds, and text styling

body {
  background-color: #f4f4f4;
  color: #333333;
}

h1 {
  color: darkblue;
  text-align: center;
}

p {
  font-size: 18px;
  line-height: 1.6;
}

Chapter 6: Fonts

body {
  font-family: Arial, sans-serif;
}

h1 {
  font-weight: bold;
}

Fonts affect readability and design. Choose simple fonts first while learning.

Chapter 7: The box model

Every element is a box made of content, padding, border, and margin. 

.box {
  width: 250px;
  padding: 20px;
  border: 2px solid black;
  margin: 30px;
}
  • Padding is inner space.
  • Margin is outer space.
  • Border is the visible boundary.

Chapter 8: Width, height, and units

  • `px` for fixed size
  • `%` for relative size
  • `rem` for scalable text and spacing
  • `vh` and `vw` for viewport size

Chapter 9: Display values

.one { display: block; }
.two { display: inline; }
.three { display: inline-block; }
.four { display: none; }

These values control how elements behave in the page flow.

Chapter 10: Positioning

  • `static` is default
  • `relative` moves from normal position
  • `absolute` positions against the nearest positioned parent
  • `fixed` stays fixed on screen
  • `sticky` sticks after a scroll point
.badge {
  position: absolute;
  top: 10px;
  right: 10px;
}

Chapter 11: Flexbox

Flexbox is used when you want items in a row or column and need easy alignment. 

.container {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 12px;
}
Use Flexbox for navbars, rows of cards, centered content, and button groups.

Chapter 12: CSS Grid

Grid is used for two-dimensional layouts with rows and columns. 

.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}

Chapter 13: Responsive design

A responsive page works properly on mobile, tablet, and desktop. 

@media (max-width: 768px) {
  .grid {
    grid-template-columns: 1fr;
  }
}

Chapter 14: Pseudo-classes and hover effects

a:hover {
  color: red;
}

input:focus {
  border-color: blue;
}

Chapter 15: Transitions and basic animations

button {
  transition: background-color 0.3s ease;
}

button:hover {
  background-color: teal;
}

Use animation carefully. It should help the user, not distract the user.

Chapter 16: Practice project ideas for CSS

  1. Style your profile page.
  2. Create a navbar.
  3. Create a card layout.
  4. Create a responsive landing page.
Goal before moving to JavaScript: you should be comfortable styling a page, using spacing correctly, and building simple layouts with Flexbox and Grid.
