Learn JavaScript from Scratch

JavaScript is the programming language of the browser. It adds behavior, logic, and interaction to webpages.

Chapter 1: What JavaScript is and why we use it

HTML creates the structure. CSS styles the structure. JavaScript makes the page respond to user actions and data changes.

  • It responds to clicks.
  • It changes text and styles.
  • It validates forms.
  • It fetches data from APIs.

Chapter 2: Adding JavaScript to a webpage

<script src="script.js"></script>
console.log("JavaScript connected");

Chapter 3: Variables

const name = "Aman";
let age = 21;
  • Use `const` when the value will not change.
  • Use `let` when the value may change later.

Chapter 4: Data types

const userName = "Riya";    // string
const marks = 90;          // number
const isPassed = true;     // boolean
const city = null;         // null
let phone;                 // undefined

Chapter 5: Operators

console.log(5 + 2);
console.log(10 > 4);
console.log(true && false);
  • Arithmetic operators do math.
  • Comparison operators compare values.
  • Logical operators combine conditions.

Chapter 6: Conditions

const age = 20;

if (age >= 18) {
  console.log("Adult");
} else {
  console.log("Minor");
}

Chapter 7: Loops

for (let i = 1; i <= 5; i += 1) {
  console.log(i);
}
let count = 1;
while (count <= 3) {
  console.log(count);
  count += 1;
}

Chapter 8: Functions

function add(a, b) {
  return a + b;
}

console.log(add(4, 6));

Functions help you write reusable code.

Chapter 9: Arrays

const fruits = ["Apple", "Banana", "Mango"];
console.log(fruits[0]);

Arrays are used to store lists of values.

Chapter 10: Objects

const student = {
  name: "Ravi",
  age: 22,
  city: "Pune"
};

console.log(student.name);

Objects are used to store related information together.

Chapter 11: DOM basics

DOM stands for Document Object Model. It is how JavaScript reads and changes HTML. 

const heading = document.getElementById("title");
heading.textContent = "New title";

Chapter 12: Events

const button = document.getElementById("btn");

button.addEventListener("click", function () {
  console.log("Button clicked");
});
  • `click` happens when the user clicks.
  • `input` happens when the user types.
  • `submit` happens when a form is submitted.

Chapter 13: Form handling

const form = document.getElementById("contactForm");

form.addEventListener("submit", function (event) {
  event.preventDefault();
  console.log("Form submitted");
});

`preventDefault()` stops the browser's default form submission so you can validate or handle the data first.

Chapter 14: Array methods

const numbers = [4, 8, 12, 16];

const bigNumbers = numbers.filter(function (number) {
  return number > 10;
});

console.log(bigNumbers);
  • `forEach` loops through items.
  • `map` transforms items.
  • `filter` keeps selected items.
  • `find` returns one matching item.

Chapter 15: Modern JavaScript syntax

const user = "Riya";
console.log(`Hello, ${user}`);

const add = (a, b) => a + b;

Learn template literals and arrow functions after you understand normal syntax first.

Chapter 16: Async JavaScript and fetch

async function loadPosts() {
  const response = await fetch("https://jsonplaceholder.typicode.com/posts");
  const posts = await response.json();
  console.log(posts);
}

loadPosts();

Use async code when something takes time, like getting data from a server.

Chapter 17: Local storage

localStorage.setItem("username", "Aman");
const savedName = localStorage.getItem("username");
console.log(savedName);

Local storage keeps small pieces of data in the browser.

Chapter 18: Debugging

  • Use `console.log()` to inspect values.
  • Read browser errors carefully.
  • Check spelling of variable names and IDs.
  • Use DevTools to inspect DOM elements.
