Web Fundamentals TL;DR

Compact revision notes made from your class topics. Focused on what, why, where, how, comparisons, and interview-ready answers.

Jump to Interview Q&A

1. Why the Web Exists

What: The World Wide Web is a system for accessing and sharing documents and resources over the Internet.

Why: It solved the problem of isolated computers and difficult information sharing.

Where Used: Websites, web apps, education portals, e-commerce, banking, social media.

How: Browser + URL + HTTP/HTTPS + server work together to fetch and display resources.

Core idea: Access information from anywhere using standard rules.

2. Internet vs Web

Concept Meaning Interview Line
Internet Global network of connected computers Infrastructure
Web Collection of websites and web resources on the Internet Application/service on top of the Internet

3. Core Components of the Web

Client

What: Browser that sends requests and shows output.

Examples: Chrome, Firefox, Edge.

Why: Acts as interface between user and web.

Server

What: System that receives requests and returns resources/data.

Examples: Apache, Nginx, Spring Boot server.

Why: Centralized processing and data access.

Protocol

What: Rules of communication.

Examples: HTTP, HTTPS.

Why: Standard format for request-response exchange.

DNS

What: Converts domain name into IP address.

Why: Humans remember names; computers use numbers.

7. Semantic HTML

What: HTML tags that carry meaning, not just appearance.

Why: Better SEO, accessibility, readability, and maintainability.

Where Used: Blogs, landing pages, article pages, dashboards, web apps.

How: Replace generic containers with meaningful tags like <header>, <main>, <article>.

16. Interview Preparation

Conceptual Questions

Q: What happens when you enter a URL?

A: DNS resolution, TCP connection, HTTP request, server processing, HTTP response, browser rendering.

Q: What is client-server architecture?

A: Client sends requests, server processes them and sends responses.

Q: What is DOM?

A: A tree representation of the HTML document created by the browser.

Q: Why semantic HTML?

A: Better SEO, accessibility, and readable structure.

Q: Difference between SPA and MPA?

A: SPA updates content without full reload; MPA loads a new page for each route.

Scenario-Based Questions

Q: A website is slow to open. What could be the reason?

A: DNS delay, slow server, heavy database query, large response, or slow browser rendering.

Q: Why prefer class over id for repeated components?

A: Because class is reusable across multiple elements.

Coding / Real-World Questions

Q: Write semantic page structure.

A: Use header, nav, main, section, article, footer.

Q: Write a safe anchor tag opening in new tab.

A: Use target="_blank" with rel="noopener noreferrer".
